# Word list credits

`src/main/assets/words.txt` is generated by `tools/build_words.py`
(`pip install wordfreq`, `npm pack wordlist-english`, then
`python tools/build_words.py src/main/assets/words.txt`).

- Word frequencies: [wordfreq](https://github.com/rspeer/wordfreq) by Robyn Speer,
  data licensed CC BY-SA 4.0.
- Spelling check: [wordlist-english](https://github.com/jacksonrayhamilton/wordlist-english),
  built from SCOWL by Kevin Atkinson (MIT-style licence).
